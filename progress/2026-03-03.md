## Issues

- publishedAt was set on BenchmarkReport but not BenchmarkCycle — leaderboard queries cycle.publishedAt, so rankings didn't appear despite cycle being Completed. Fixed with manual DB update + code fix.
- Last 3 Vercel deploys failed due to pre-existing TypeScript error in run-cycle.ts (ModelEvaluation createMany type mismatch). Fixed by using Prisma.ModelEvaluationCreateManyInput[] type.
- Segment filters showed "No scores available" because run-cycle.ts only calculated overall composite scores. Added per-segment scoring loop.

## Lessons Learned

- Always verify that state transitions set ALL relevant timestamps, not just the state field
- TypeScript type inference from Prisma's `create` method includes relational types incompatible with `createMany` — use the explicit `CreateManyInput` type
- WebFetch tool has 15-minute cache — use cache-busting query params to verify live deployments
- Per-segment scoring reuses the same score data as overall — just filter by tool-segment mappings and rank independently
