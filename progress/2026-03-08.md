- **Root Cause**: Re-running 1,632 upserts on resume exhausted Neon serverless connection pool
- **Fix**: Added synthesis skip check — if records already exist, skip directly to composites
- **Result**: Resume time went from "hang indefinitely" to 44.7 seconds
- **Prevention**: All pipeline stages now check for existing records before re-processing
