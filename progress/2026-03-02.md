## Issues

- Neon free tier connection pooler has hard limits — caused pool exhaustion on long benchmark runs. Fixed with lower connection_limit (5), higher timeout (60s), batch writes, and retry logic.
- 2 OpenRouter model IDs from the recommendation doc didn't exist (gemini-3-pro, grok-4). Substituted with available alternatives.
- Custom YAML parser failed on nested multiline arrays — replaced with `yaml` npm package (from Sprint 1).

## Lessons Learned

- Neon's free tier pooler needs conservative connection settings for long-running batch scripts (connection_limit=5, pool_timeout=60)
- OpenRouter model IDs should be verified against their API before committing — model naming doesn't always match what's available
- Separating methodology into a public YAML repo makes the benchmark auditable and transparent without exposing application logic
- `createMany` is significantly more pool-friendly than sequential `create` calls in tight loops
- Prisma compound unique constraints with nullable fields can't use upsert — need findFirst + create/update pattern
