## Document Purpose

This guide governs how the AISearchArena sub-brand extends from the AI Search Mastery parent brand. It defines what is inherited, what diverges, and why. It addresses the central tension of the brand architecture: AISearchArena is part of a branded house whose other properties include products that compete in the market the benchmark evaluates.

Every visual, verbal, and structural brand decision for AISearchArena should trace back to this document. It is the operating manual for brand consistency across properties and brand independence within the benchmark.

## 1. Brand Extension Framework

### 1.1 The Branded House Model

AI Search Mastery operates a branded house architecture. All four properties share a parent visual identity system, voice principles, and values framework. Each property expresses those shared elements through a dedicated accent colour and role-specific adaptations.

```
AI Search Mastery (Parent Hub)
  |-- aisearchmastery.com     -- Knowledge and strategy hub      [Signal Blue #2563EB]
  |-- aimpactscanner.com      -- Diagnostic tool (product)       [Clarity Teal #0D9488]
  |-- llmtxtmastery.com       -- Optimization tool (product)     [Action Amber #D97706]
  |-- aisearcharena.com       -- Independent benchmark           [Arena Slate #475569]
```

### 1.2 What AISearchArena Inherits from the Parent

The following elements carry forward to AISearchArena without modification:

| Element | Parent Standard | AISearchArena Application |
|---|---|---|
| **Typography** | Inter (exclusively), modular scale | Identical. No additional typefaces |
| **Primary colour palette** | Mastery Blue #1E3A5F as anchor colour | Used in shared navigation, footer, and parent attribution |
| **Values framework** | 5 parent values (Clarity Over Cleverness, Honesty Over Hype, Action Over Analysis, Accessibility Is The Mission, Build To Evolve) | Inherited as foundation. Extended with 5 benchmark-specific values |
| **Brand archetype** | The Guide | Inherited as parent archetype. AISearchArena expresses it as "The Evaluator" -- a Guide who helps through structured measurement rather than instruction |
| **Voice principles** | Plain language, practitioner-grounded, honest about limitations | Inherited. Adapted for data-forward benchmark context (see Section 3) |
| **Footer attribution** | "Part of AI Search Mastery" | Applied consistently on every page |
| **Card-based layout patterns** | Consistent card styling across properties | Used for tool profiles and category displays |
| **CTA standards** | Action-oriented, benefit-clear | Applied with benchmark-specific actions ("View Methodology," "Compare Tools") |

### 1.3 Where AISearchArena Diverges

The following elements are distinct to AISearchArena, serving its unique role as an independent evaluation property:

| Element | Parent Standard | AISearchArena Divergence | Rationale |
|---|---|---|---|
| **Brand essence** | Clarity | Rigor | Benchmark credibility demands a distinct quality. Rigor is the mechanism that produces clarity in a comparative evaluation context |
| **Accent colour** | Signal Blue #2563EB (parent hub) | Arena Slate #475569 | Neutral, authoritative tone suited to evaluation. Deliberately avoids the energy/warmth of product sub-brands (see Section 2.1) |
| **Tone emphasis** | Educational, encouraging | Data-driven, methodology-forward | The benchmark teaches through evidence, not instruction |
| **Content format** | Articles, guides, tutorials | Benchmark reports, tool profiles, methodology documentation, trend analyses | Structured data output rather than editorial content |
| **Commercial posture** | Promotes ecosystem products | Evaluates market; does not promote | Editorial independence is a structural requirement |
| **Disclosure requirements** | Standard business disclosures | Prominent conflict of interest disclosure on every report and page | The benchmark evaluates a market that includes parent brand products |

### 1.4 The Independence-Belonging Tension

AISearchArena must simultaneously signal two things:

1. **It belongs to AI Search Mastery.** The branded house architecture is not hidden. Parent brand credibility, practitioner expertise, and audience trust contribute to the benchmark's launch position.

2. **Its editorial output is independent of AI Search Mastery's commercial interests.** Benchmark scores, methodology decisions, and vendor communications are not influenced by the parent brand's product strategy.

This tension is managed through three mechanisms:

- **Visual cues**: Arena Slate accent colour is deliberately cooler and more neutral than the warmer product-brand accents. It signals analytical distance without breaking from the visual system.
- **Verbal cues**: Benchmark content uses data-forward language and does not include cross-promotional language for parent brand products.
- **Structural cues**: Conflict of interest disclosure appears prominently. Methodology is published and locked per cycle. Vendor disclosure process applies equally to parent brand products.

The goal is not to hide the relationship. It is to demonstrate that the relationship does not compromise the evaluation.

## 2. Visual Identity Extension

### 2.1 Accent Colour: Arena Slate

**Primary accent**: Arena Slate #475569

**Rationale for selection**:

The three existing sub-brands use colours with varying degrees of energy and warmth:
- Signal Blue #2563EB -- vibrant, action-oriented (knowledge hub)
- Clarity Teal #0D9488 -- fresh, diagnostic (scanner product)
- Action Amber #D97706 -- warm, tool-oriented (optimization product)

Arena Slate occupies the remaining position: cool, neutral, authoritative. It communicates:
- **Analytical detachment** -- appropriate for independent evaluation
- **Seriousness** -- the benchmark is rigorous work, not a marketing exercise
- **Neutrality** -- no tool or category is favoured
- **Durability** -- slate does not trend; it persists

Arena Slate is not a brand that excites. It is a brand that earns trust through consistency. This is deliberate.

**Extended palette for benchmark-specific use**:

| Colour | Hex | Usage |
|---|---|---|
| **Arena Slate** (primary accent) | #475569 | Headers, primary CTAs, navigation accents, benchmark branding |
| **Arena Slate Light** | #64748B | Secondary text, supporting UI elements, section dividers |
| **Arena Slate Pale** | #CBD5E1 | Backgrounds, card borders, inactive states |
| **Confidence Green** | #059669 | High confidence scores, positive trend indicators |
| **Caution Amber** | #D97706 | Medium confidence scores, caution indicators |
| **Insufficient Red** | #DC2626 | Low confidence, insufficient data indicators, decline trends |
| **Neutral Grey** | #9CA3AF | Baseline states, no-change indicators, disabled elements |
| **Mastery Blue** (parent anchor) | #1E3A5F | Footer, parent attribution bar, shared navigation elements |

**Colour usage rules**:

1. Arena Slate is the dominant accent on all AISearchArena pages. Mastery Blue appears only in parent attribution areas (footer, shared navigation bar).
2. Signal Blue, Clarity Teal, and Action Amber do not appear on AISearchArena pages. These are reserved for their respective sub-brands. Using product-brand colours on the benchmark site would visually associate the benchmark with specific products.
3. Confidence Green, Caution Amber, and Insufficient Red are functional colours used exclusively for score confidence indicators and trend displays. They are not used for decorative purposes.
4. Note that Caution Amber shares the hex value with Action Amber (#D97706). On AISearchArena, this colour appears only in functional confidence/trend contexts, never as a brand accent. Context (confidence tags, trend arrows) prevents visual association with the LLM.txt Mastery sub-brand.

### 2.5 Imagery and Illustration

**AISearchArena does not use stock photography.** Benchmark content is data-driven. Images add visual noise without informational value in this context.

Permitted visual elements:
- Charts and data visualizations (see sparkline and table standards above)
- Tool logos (sourced from vendors; displayed at consistent sizes in evaluation contexts)
- Iconography for categories and metrics (simple, line-style, monochrome Arena Slate)
- Diagrams for methodology explanation (clean, labelled, Inter typography)

Prohibited visual elements:
- Stock photos of people, offices, or abstract "technology" imagery
- Decorative illustrations unrelated to benchmark data
- Gradient backgrounds or patterned fills that compete with data displays
- Vendor marketing screenshots used as hero images (these may appear within tool profile evaluations as evidence, not decoration)

## 3. Voice and Tone Extension

### 3.1 Parent Voice Foundation

AI Search Mastery's voice is defined by its archetype (The Guide) and five principles: Clarity Over Cleverness, Honesty Over Hype, Action Over Analysis, Accessibility Is The Mission, Build To Evolve. AISearchArena inherits all five principles and expresses them through a benchmark-specific lens.

### 3.2 AISearchArena Voice Characteristics

| Characteristic | Parent Expression | AISearchArena Expression |
|---|---|---|
| **Archetype** | The Guide (teaches, empowers) | The Evaluator (measures, reports, lets data guide decisions) |
| **Tone** | Warm, encouraging, practitioner-first | Measured, precise, data-forward, still practitioner-first |
| **Emotional register** | "You can do this. Here is how." | "Here is what we found. Here is the evidence." |
| **Authority source** | Experience and expertise | Methodology and evidence |
| **Engagement mode** | Instructive | Informative |
| **Uncertainty handling** | "This area is evolving. Here is what we know so far." | "Confidence: Medium. This score is based on limited data. See methodology note M-14." |

### 3.3 Voice Principles Applied to Benchmark Content

**Clarity Over Cleverness in the benchmark**:
- Scores are presented without editorializing. The number, the confidence tag, and the evidence are the message.
- Methodology documentation is written for a marketing professional with 3 years of experience, not an analyst or academic.
- When a concept requires technical explanation, provide it inline. Do not send readers to a glossary.

**Honesty Over Hype in the benchmark**:
- Name the conflict of interest directly. Do not soften it to "potential" conflict or "perceived" conflict.
- When data is insufficient, say so. A blank score with "Insufficient Data" is more honest than a guess.
- Never use superlatives about the benchmark itself ("the best," "the most trusted," "definitive"). Let the work earn those descriptions from others.

**Action Over Analysis in the benchmark**:
- Every benchmark report must answer: "What should a practitioner do with this information?" Not prescriptive recommendations, but actionable framing. "Tool X scored highest in monitoring for businesses with fewer than 50 pages" is actionable. "Tool X has a robust monitoring capability" is not.
- Do not produce analysis for its own sake. If a metric does not help a practitioner make a decision, question whether it belongs in the benchmark.

**Accessibility Is The Mission in the benchmark**:
- Write for practitioners, not analysts. If a sentence requires knowledge of statistical methodology to understand, rewrite it.
- Provide context with every score. A score of 7.2 means nothing without knowing the scale (1-10), the category average (6.8), and the confidence level (High).
- Pricing data is included where available because practitioners operate within budgets.

**Build To Evolve in the benchmark**:
- Methodology changes are versioned and explained, not quietly introduced.
- Historical data is preserved even when methodology evolves. Provide comparison guidance across methodology versions.
- The benchmark will improve. Say so explicitly. "Version 1 of this methodology evaluates X metrics. Future versions will expand to include Y based on practitioner feedback."

### 3.4 Tone by Content Type

#### Monthly Benchmark Reports

**Tone**: Factual, data-forward, structured.

- Lead with findings, not framing. The first paragraph of a benchmark report states the top-level results, not the importance of benchmarking.
- Use active voice for methodology descriptions: "We evaluated 27 tools" not "27 tools were evaluated."
- Use passive voice for results where the methodology is the actor: "Tool X scored 8.2" (the score is what matters, not who assigned it).
- Every claim has a citation to specific methodology, evidence, or data point.
- No promotional language about any tool, including AI Search Mastery products. Scores speak; adjectives do not.

**Example**:
> In the February 2026 evaluation, SearchOptimizer Pro scored 8.4 overall (confidence: High), maintaining the top position in the Monitoring category for the third consecutive month. GEOTracker rose to second position at 7.9 (confidence: High), driven by improvements in its reporting module. Four tools scored below the category average of 6.8; two declined from January scores.

**Not this**:
> Great news for SearchOptimizer Pro fans -- they have done it again! The powerful tool continues to dominate our rankings with an impressive 8.4 score.

#### Methodology Documentation

**Tone**: Precise, procedural, exhaustive.

- Written as a reference document, not a narrative. Structured with numbered sections and subsections.
- Every term is defined on first use.
- Every decision (why this metric, why this weighting, why this prompt rotation strategy) is explained with rationale.
- Methodology documentation is not marketing content. It exists to enable verification, not to persuade.

**Example**:
> 4.3.2 Prompt Rotation Strategy
>
> Each evaluation cycle uses a standardized prompt set comprising 70% fixed prompts (consistent across all cycles for longitudinal comparability) and 30% rotated prompts (refreshed each cycle to prevent tool optimization gaming). Fixed prompts are published in Appendix B. Rotated prompts are published after the evaluation cycle closes. The rotation selection process is documented in Section 4.3.3.

#### Vendor Communications

**Tone**: Professional, constructive, firm on process.

- Vendors are stakeholders, not adversaries and not customers.
- Communications are respectful but do not negotiate on methodology or timing.
- Pre-publication notifications follow a standard template (see Section 4).
- Responses to vendor objections reference specific methodology sections. "Per Section 4.3.2 of the published methodology..." is a legitimate response.
- Never apologize for a low score. The score reflects the methodology. If the methodology is flawed, fix the methodology for the next cycle and document the change.

**Example**:
> Thank you for your disclosure submission. We have reviewed the information provided and updated the factual elements in our evaluation as noted in the attached correction log. The overall score methodology remains unchanged per the published evaluation framework (v1.2, Section 4). If you believe a factual error remains, please identify the specific metric and provide supporting evidence.

#### Press and Media Materials

**Tone**: Accessible, quotable, data-anchored.

- Lead with the most newsworthy finding. What changed? What is new? What trend emerged?
- Provide 2-3 quotable sentences that include specific data points.
- Always include the conflict of interest disclosure, even in press materials. Media will check.
- Do not overstate significance. "The largest month-over-month category shift we have observed" is specific and verifiable. "A seismic shift in the market" is not.

**Example**:
> The March 2026 benchmark evaluated 29 AI search optimization tools across 52 metrics. Three tools entered the evaluation for the first time. The Monitoring category saw the largest score dispersion of any category this cycle, with a 4.2-point gap between the highest and lowest scores. Full methodology and conflict of interest disclosure are available at aisearcharena.com/methodology.

#### Social Media

**Tone**: Concise, data-first, methodology-referencing.

- Social posts from AISearchArena share data points, methodology updates, and publication announcements.
- No promotional language. No enthusiasm markers (exclamation marks, "exciting," "incredible").
- Every social post about benchmark results links to the full report.
- No engagement-bait framing. "Which tool is YOUR favourite?" is not AISearchArena content.

**Example**:
> February benchmark published. 27 tools, 7 categories, 50+ metrics. Three tools improved scores by >10% month-over-month. Two declined. Full results and methodology: [link]

**Not this**:
> The results are IN! Check out which AI search tools came out on top this month. You might be surprised! [link]

### 3.5 Vocabulary Standards

The positioning statement (v1.0, Section 8) defines "What We Say" and "What We Don't Say" vocabularies. Those standards are incorporated by reference here and apply to all AISearchArena brand communications.

Additional vocabulary guidance specific to the Brand Extension Guide:

| Context | Use | Do Not Use |
|---|---|---|
| Referring to the benchmark | "The benchmark," "the evaluation," "the monthly assessment" | "Our review," "our opinion," "our recommendation" |
| Referring to results | "Scores earned," "tool scored X," "evaluation results" | "Scores given," "we rated," "our rating" |
| Referring to the parent brand | "AI Search Mastery," "the parent brand," "the ecosystem" | "Our company," "headquarters," "corporate" |
| Referring to the conflict | "Conflict of interest," "disclosed conflict" | "Potential conflict," "perceived conflict," "possible bias" |
| Referring to AI Search Mastery products in benchmark context | "AImpactScanner (an AI Search Mastery product)," "LLM.txt Mastery (an AI Search Mastery product)" | "Our product," "our tool," "our sister product" |
| Describing benchmark scope | "Evaluates," "assesses," "measures," "benchmarks" | "Reviews," "ranks," "judges," "rates" |

## 4. Content Framework

### 4.1 Monthly Benchmark Report Template

Every monthly benchmark report follows this structure. Deviations require documented justification.

#### Report Structure

```
1. Report Header
   - Title: "AISearchArena Monthly Benchmark -- [Month] [Year]"
   - Subtitle: "[N] tools evaluated across [N] categories and [N] metrics"
   - Methodology version reference
   - Conflict of interest disclosure (inline, not linked)
   - Publication date and data collection period

2. Executive Summary (300-500 words)
   - Top-level findings (3-5 bullet points)
   - Significant changes from previous month
   - New tools entering evaluation
   - Category-level trends

3. Methodology Summary
   - Link to full methodology page
   - Note any methodology changes from previous cycle
   - Prompt rotation disclosure for this cycle

4. Overall Rankings
   - Full comparison table with all tools
   - Scores, confidence tags, trend indicators
   - Sortable by category, score, or trend

5. Category Breakdowns (one section per category)
   - Category definition and relevance
   - Category comparison table
   - Notable movements and trends
   - Practitioner context ("this category matters most if...")

6. Tool Spotlight (2-3 tools per report)
   - Tools that moved significantly (up or down)
   - New entrants with first evaluation
   - Context for the movement

7. Trend Analysis
   - Market-level trends visible in the data
   - Category convergence or divergence patterns
   - Longitudinal observations (available after 3+ months)

8. Conflict of Interest Disclosure (full)
   - Standard disclosure statement
   - AI Search Mastery product scores highlighted for transparency
   - Any additional disclosures for this cycle

9. Methodology Notes
   - Specific methodology decisions relevant to this cycle
   - Known limitations
   - Planned methodology improvements

10. Appendices
    - Full scoring data (downloadable)
    - Evidence artifact references
    - Vendor disclosure status table
    - Correction log (if applicable)
```

#### Design Standards for Reports

- Report pages use a single-column layout (max width: 780px) for readability
- Comparison tables are full-width within the content column
- Score displays use the standardized score visual system (Section 2.3)
- Charts use Arena Slate line/bar colours with functional colours only for confidence/trend
- Disclosure block has a visible border (left border, 3px solid Arena Slate) and slightly inset from content margin
- Report header includes a visual marker (Arena Slate horizontal rule) separating the report from site navigation

### 4.2 Individual Tool Profile Template

```
1. Tool Header
   - Tool name and vendor
   - Tool logo (vendor-supplied, displayed at 48x48px)
   - Category badges for all applicable categories
   - Overall score with confidence tag
   - Trend indicator (vs. previous month)
   - Last evaluated: [date]

2. Score Breakdown
   - Score per category with confidence tags
   - Sparkline chart showing score trajectory (after 3 months)

3. What This Tool Does (2-3 sentences)
   - Factual description of tool capabilities
   - Sourced from vendor documentation and evaluation

4. Where It Scores Well
   - Top 3 categories by relative performance
   - Specific metrics driving high scores

5. Where It Scores Below Average
   - Categories below the overall category average
   - Specific metrics driving lower scores

6. Practitioner Context
   - "Best suited for:" (derived from score profile, not editorial opinion)
   - Pricing tier (if publicly available)
   - Integration compatibility notes

7. Vendor Disclosure Status
   - Whether the vendor submitted a disclosure for this cycle
   - Link to vendor disclosure (if submitted and published)

8. Historical Data
   - Score history table (all evaluated months)
   - Methodology version notes for each period

9. Conflict Disclosure (if applicable)
   - If this tool is an AI Search Mastery product, the full conflict disclosure appears here
   - This section is absent for non-affiliated tools (do not include an empty section)
```

### 4.4 Conflict of Interest Disclosure Standards

**Full disclosure** (appears on methodology page and in every benchmark report):

> **Conflict of Interest Disclosure**
>
> AISearchArena is operated by AI Search Mastery, which also operates AImpactScanner (aimpactscanner.com) and LLM.txt Mastery (llmtxtmastery.com). Both products exist in the market this benchmark evaluates.
>
> We manage this conflict through: published methodology locked before each evaluation cycle; multi-source evaluation synthesis from 6 independent analyses; evidence artifact requirements for every score; confidence tagging on all evaluations; identical vendor disclosure process for AI Search Mastery products; and a policy of publishing all scores regardless of outcome.
>
> The complete methodology is available for independent verification. We believe transparent, structured evaluation with a disclosed conflict produces better practitioner outcomes than no independent benchmark at all.

**Inline disclosure** (appears on tool profiles, category pages, social media bios):

> AISearchArena is part of AI Search Mastery, which operates products in the benchmarked market. Full conflict disclosure and methodology: aisearcharena.com/methodology

**Report-level disclosure for AI Search Mastery products**:

### 4.6 Right-of-Reply Handling

When a vendor submits a right-of-reply:

1. The response is published alongside the tool's evaluation results in the benchmark report, clearly labelled: **"Vendor Response from [Vendor Name]"**
2. The response is published as submitted, without editorial modification. Spelling and formatting may be normalized; content is not altered.
3. Maximum length: 500 words. Submissions exceeding this limit are returned with a request to edit down.
4. AISearchArena does not respond to vendor responses within the benchmark report. If the vendor response raises factual issues, those are addressed in the next evaluation cycle's correction log.
5. Right-of-reply responses are preserved in the historical record alongside the evaluation they respond to.

## 5. Cross-Property Guidelines

### 5.1 Foundational Principle

AISearchArena evaluates a market. AI Search Mastery and its other properties operate in that market. Cross-property references must preserve the benchmark's editorial independence while acknowledging the shared ecosystem.

The rule is simple: **information flows; influence does not.**

### 5.2 How AISearchArena References Other AI Search Mastery Properties

| Context | Permitted | Not Permitted |
|---|---|---|
| **Benchmark reports** | Evaluate AI Search Mastery products using identical methodology, with enhanced disclosure | Favourable editorial commentary, promotional language, softer scoring, delayed publication of poor scores |
| **Methodology page** | Name the conflict. List the products. Link to the disclosure | Minimize the relationship. Use "potential" conflict language. Omit any current products |
| **Tool profiles** | Include tool profiles for AI Search Mastery products with full evaluation data and conflict disclosure | Feature AI Search Mastery products more prominently than other tools. Provide additional context not available for competing tools |
| **Site navigation** | Footer: "Part of AI Search Mastery" attribution. No navigation links to other property product pages | "Try AImpactScanner" CTAs. Cross-promotional banners. "From the makers of" messaging in benchmark content areas |
| **Social media** | Share benchmark data about AI Search Mastery products with the same treatment as any other tool | Promotional framing of AI Search Mastery product scores. "Proud to announce" language about affiliated tool performance |

### 5.3 How Other AI Search Mastery Properties Reference AISearchArena

| Context | Permitted | Not Permitted |
|---|---|---|
| **Parent hub (aisearchmastery.com)** | Link to benchmark. Reference AISearchArena as "our independent benchmark." Cite benchmark data with attribution ("According to the AISearchArena February 2026 benchmark...") | Cherry-pick favourable scores for AI Search Mastery products. Omit unfavourable scores when citing benchmark data. Frame benchmark as validation of ecosystem products |
| **Product properties (AImpactScanner, LLM.txt Mastery)** | Display their own AISearchArena scores with full context (overall score, category scores, confidence tags, link to full evaluation). Use badge system (see Section 8) if eligible | Display scores without confidence tags. Display category scores selectively (showing only high scores). Modify badge design or remove attribution |
| **Marketing materials** | Reference benchmark existence as evidence of ecosystem commitment to transparency and honest evaluation | Use benchmark data in product marketing without full context. Imply that benchmark scores constitute endorsements |
| **Sales conversations** | Reference the benchmark as a third-party resource prospects can consult | Pre-select benchmark data to show only favourable results. Frame the benchmark as a marketing asset |

### 5.4 Data Citation Rules

When any AI Search Mastery property cites AISearchArena benchmark data:

1. **Attribution is required**: "Source: AISearchArena [Month] [Year] Benchmark" with link to the full report
2. **Context is required**: Overall score must be accompanied by confidence tag and evaluation date
3. **Selectivity is restricted**: If citing category scores, all category scores from that evaluation must be available via link. Cherry-picking categories is prohibited
4. **Recency is required**: Cited data must be from the most recent benchmark cycle. If using historical data, the date must be clearly stated
5. **Methodology version noted**: If citing data from a previous methodology version, note the methodology version and any relevant changes

- **Retargeting**: Visitors to AISearchArena benchmark content are not retargeted with product ads for AI Search Mastery products. This would undermine the editorial independence positioning.

## 6. Independence Safeguards in Brand

### 6.1 Visual Signals of Independence

The brand's visual treatment reinforces the independence positioning through deliberate design choices:

| Visual Element | Independence Signal |
|---|---|
| **Arena Slate accent colour** | Cool, neutral tone contrasts with warmer product-brand colours. Communicates analytical detachment |
| **No product-brand colours** | Signal Blue, Clarity Teal, and Action Amber do not appear on the benchmark site. This visually separates the benchmark from the products |
| **Disclosure block styling** | Left-border treatment with Arena Slate, slightly inset. Visible but not alarming. Signals transparency as a feature, not a warning |
| **Tool logo display** | All tool logos displayed at identical size and treatment. No visual hierarchy based on vendor relationship |
| **Equal page treatment** | AI Search Mastery product profiles use identical layouts to all other tool profiles. No enhanced or diminished treatment |
| **Methodology link prominence** | Methodology page is accessible from primary navigation, not buried in footer. Visual treatment signals "this is important" not "this is fine print" |

### 6.2 Verbal Signals of Independence

| Verbal Element | Independence Signal |
|---|---|
| **"Scores earned"** | Active framing: tools earn their scores through methodology application. The benchmark does not give or assign scores |
| **Direct conflict naming** | "Conflict of interest" -- not "potential" conflict, not "perceived" conflict. Direct naming signals comfort with the tension |
| **Methodology references** | In-content references to specific methodology sections ("per Section 4.3.2") signal that an external, verifiable framework governs decisions |
| **Consistent vocabulary** | Same language used for all tools regardless of affiliation. No softening for AI Search Mastery products; no hardening for competitors |
| **"We believe" framing** | When expressing editorial positions about the benchmark's value proposition, using "we believe" acknowledges that it is a position, not a fact |

### 6.3 The "Part of AI Search Mastery" Attribution

**Format**: "Part of AI Search Mastery" appears in the site footer and in the wordmark's extended form.

**Treatment**:
- Set in Inter Regular, Neutral Grey (#9CA3AF)
- Visually subordinate to the AISearchArena wordmark
- Links to aisearchmastery.com
- Does not include taglines, product names, or promotional text
- Does not change based on page content or context

**Rationale**: The attribution is honest (AISearchArena is part of AI Search Mastery) and proportional (it is present but not dominant). It acknowledges the relationship without positioning the benchmark as a marketing extension of the parent brand.

**What the attribution is not**:
- It is not "Powered by AI Search Mastery" (implies dependency)
- It is not "From AI Search Mastery" (implies product relationship)
- It is not "An AI Search Mastery Publication" (implies editorial control)
- It is not "Brought to you by AI Search Mastery" (implies sponsorship)

"Part of" is the correct framing. AISearchArena is part of the ecosystem. The ecosystem does not control the benchmark.

Before publishing any AISearchArena content, verify:

- [ ] No cross-promotional CTAs or links to product properties within benchmark content

## 8. Badge and Certification System

### 8.1 Overview

AISearchArena provides embeddable badges that vendors can display on their websites and marketing materials to reference their benchmark evaluation results. Badges are a privilege, not a right. They carry specific usage rules designed to protect benchmark credibility.

### 8.2 Badge Types

#### Evaluated Badge

Available to any tool that has been evaluated in at least one benchmark cycle.

```
+---------------------------------------+
|  AISearchArena                        |
|  EVALUATED                            |
|  [Month] [Year]                       |
|  aisearcharena.com                    |
+---------------------------------------+
```

- Colour: Arena Slate border and text on white background
- Does not display a score
- Indicates that the tool has been evaluated using the AISearchArena methodology
- Links to the tool's profile page on aisearcharena.com

#### Score Badge

Available to any tool with an overall score and a High or Medium confidence rating.

```
+---------------------------------------+
|  AISearchArena                        |
|  Score: [X.X]  Confidence: [LEVEL]    |
|  [Month] [Year] Benchmark             |
|  aisearcharena.com/tools/[slug]       |
+---------------------------------------+
```

- Colour: Arena Slate border and text on white background. Confidence badge uses standard confidence colour system.
- Displays overall score and confidence level
- Month and year are required (scores are time-specific)
- Links to the tool's profile page for that evaluation period

#### Category Badge

Available to tools that scored in the top tier (top 3) of a specific category with High confidence.

```
+---------------------------------------+
|  AISearchArena                        |
|  Top 3: [Category Name]              |
|  Score: [X.X]  Confidence: HIGH       |
|  [Month] [Year]                       |
|  aisearcharena.com/tools/[slug]       |
+---------------------------------------+
```

- Same visual treatment as Score Badge
- Specific to one category
- Only available when confidence is High (not Medium, Low, or Insufficient)

### 8.3 Badge Usage Rules

1. **Badges must link to the source evaluation.** Every badge must hyperlink to the tool's profile page on aisearcharena.com for the relevant evaluation period. Static, unlinked badges are not permitted.

2. **Badges must display the evaluation month and year.** Scores are time-specific. A badge without a date is misleading.

3. **Badges must not be modified.** Vendors may not alter badge colours, typography, layout, or content. They may resize proportionally. They may not crop.

4. **Confidence level must be displayed on Score and Category badges.** Removing the confidence tag misrepresents the score.

5. **Outdated badges must be updated or removed.** When a new benchmark cycle publishes, badges referencing the previous cycle remain valid for 60 days. After 60 days, vendors must update to the current cycle's badge or remove the badge. This prevents permanently displaying a score from a favourable month.

6. **Selective display is permitted with limitations.** Vendors may display Category badges for categories where they scored in the top 3. They are not required to display all category badges. However, the overall Score badge (which links to the full evaluation) is the recommended primary badge.

7. **Score badges are not available for Low confidence or Insufficient Data evaluations.** Tools with Low confidence scores or Insufficient Data evaluations may only use the Evaluated badge.

8. **AI Search Mastery products follow identical badge rules.** No special badge treatment, no additional badge types, no exceptions.

### 8.4 Badge Provisioning

- Badges are generated automatically from benchmark data and available for download on each tool's profile page
- Badges are provided in SVG (scalable, recommended) and PNG (fixed sizes: 200px, 300px, 400px wide)
- Embed code (HTML with proper link attribution) is provided alongside badge files
- Badge files are updated automatically when new benchmark data publishes

### 8.5 What Happens When Scores Change

| Scenario | Badge Impact | Vendor Action Required |
|---|---|---|
| Score improves | New badge with updated score available. Old badge valid for 60 days | Update badge within 60 days |
| Score declines | New badge with updated score available. Old badge valid for 60 days | Update badge within 60 days. Vendor may switch to Evaluated badge if preferred |
| Tool loses top-3 category position | Category badge no longer available for new cycle. Old badge valid for 60 days | Remove Category badge within 60 days |
| Confidence drops to Low | Score badge no longer available. Evaluated badge still available | Switch to Evaluated badge or remove Score badge |
| Tool removed from benchmark | All badges expire immediately | Remove all AISearchArena badges |
| Methodology restatement changes a published score | Updated badge with restated score available. Original badge must be replaced within 30 days | Replace badge with restated version within 30 days |

### 8.6 Badge Misuse Response

If a vendor misuses badges (modifying design, removing attribution, displaying outdated badges beyond the 60-day window, or misrepresenting scores):

1. AISearchArena sends a written notice identifying the violation and requesting correction within 14 days.
2. If not corrected, AISearchArena publishes a note on the vendor's tool profile page: "Badge usage notice: [Tool name] is displaying an outdated/modified AISearchArena badge. Current evaluation data is available below."
3. Persistent or egregious misuse (fabricating scores, creating fake badges) results in a public notice and may affect the vendor's disclosure status in future benchmark cycles.
